## Technical subcommittee update / development updates

### Releases

- New odc-stac release
- New Explorer release (fixes OOM issues experienced by Geoscience Australia)

### Explorer OOM issues

DEA started experiencing OOM issues with Explorer 3.1.8, issue is fixed with
Explorer 3.1.10. Mitigation on older releases is to use the `--max-requests`
and `--max-requests-jitter` parameters to gunicorn.

### Pre-commit

Odc-geo and odc-stac have had pre-commit removed, they are now using Ruff
from `uv.lock` instead.

### Core changes

Core can be updated with changes made in odc-stac.

### Upcoming changes

Paul working on multiple database revisions on his own time.

### Explorer error messages

Explorer in particular is quite unhelpful, both in the user facing errors.
And the debug/CLI logs are quite inadequate.
Call out for everyone to just submit little changes, as and when they happen.
None of us have as much time as we want to work on things.

### RISE odc-loader error (mentioned last month)

Root cause was permission issues with S3. The logging in odc-loader was just
printing an error, but not what the error was. Pull request fixing that is
merged, but no odc-loader release with it yet.

### Cosigned OWS images

The development images of OWS are now cosigned, so it is possible to verify
that an image was built by the CI in the datacube-ows repository.

### Helm charts

The datacube-charts repository contains some things that haven't been updated
for 4+ years, so it would be nice to remove things that nobody is using.
CSIRO uses the Explorer and OWS Helm charts, Leon will check what they
are using.

### Renovatebot

Dependabot leaves some room for improvement, so Damien has been looking into
using Renovatebot for automatic updates.

It's possible to configure Renovatebot to automatically merge pull requests
that pass CI tests (which is essentially what we already do manually), main
reason to not give Renovatebot merge permissions are potential security
implications.
