### Reducing Explorer page sizes

Peter made some pull requests on Explorer that reduced the logo size and
minified the CSS and JavaScript. The savings of the minification is measured
in kilobytes, but multiplied by the millions of page accesses per month
to Explorer those savings add up.

### Crawlers gumming up Explorer

Peter mentioned their settings that made Explorer survive being indexed by
a user-agent reporting as `Lightpanda`:

- Paul had recommended setting a database timeout, so that was done.
- The Postgres database has pgbouncer for the read-only connections that Explorer
  and OWS use, and the reduced number of connections to the database allowed
  increasing the `work_mem` setting to 66 MB which is sufficient for a small
  ODC installation.
- The Kubernetes probe settings are described in an
  [issue](https://github.com/opendatacube/datacube-charts/issues/255)
  in the datacube-charts repository.
